# ERP-Core：两阶段与三阶段补全简短讲稿

约 4～5 分钟，可直接照着讲。详细配置和来源见 [实验整理](ERP_Core_两阶段与三阶段实验整理.md)。下面按研究逻辑展开，不代表各次历史运行的时间顺序。

## 1. 为什么做动态补全

这部分实验主要想回答一个问题：只有少量 EEG 导联时，能不能通过补全缺失导联的特征，提高分类效果？

我们设置了四种方法。O 使用全部 28 个真实导联；N 只使用 12 个真实导联；A 用固定 Prototype，也就是训练集的平均特征，补齐缺失导联；D 则根据当前样本，对这个平均特征进行动态修正。

在 ERP-Core 的当前 seed0 实验中，固定补全 A 的测试 BAcc 是 40.29%，少导联 N 是 39.73%，只提高了约 0.56 个百分点。而全导联 O 是 45.39%，仍然有明显差距。

所以我们尝试动态补全，希望补入当前样本的信息，而不只是平均模式。

## 2. 两阶段怎么做

动态补全的公式很简单：预测的缺失特征，等于固定 Prototype，加上 subject 修正量，再加上 task 修正量。

我们希望两个分支分别表达被试相关信息和任务相关信息。不过，这只是设计目标，不能因为分支叫 subject 和 task，就认为已经实现了解耦。

两阶段的第一阶段冻结 CNN，训练补全模块。我们用真实全导联的特征作为监督，通过重建损失学习补全，同时加入同被试、同任务的对比约束，以及分支交换后的重建约束。

第二阶段冻结 CNN 和补全模块，训练后面的 Transformer 和分类头。分类和推理时，只需要输入 12 个真实导联。

## 3. 两阶段效果怎么样

这里先看相同分类协议、同为 seed0、训练 30 轮的结果。

| 方法 | 测试 BAcc |
|---|---:|
| O：全导联 | 45.39% |
| N：少导联 | 39.73% |
| A：固定补全 | 40.29% |
| D：两阶段动态补全 | 37.43% |

## 5. 为什么尝试三阶段

我们进一步提出一个想法：先让模型看到完整导联，学习分支表示，再让它适应少导联补全，会不会更容易？

因此，三阶段的第一步用 28 个真实导联训练分支；第二步继承第一步的模型，改用 12 个真实导联加缺失 Prototype，学习补全；第三步再冻结补全模块，训练分类。

实际实现中，第二步仍然训练整个补全模块，也保留了对比和交换约束。所以这并不是先完全解耦、再只训练重建，而是先全导联训练，再少导联适配。

## 6. 三阶段改善了什么

三阶段尝试了几组不同的重建损失权重，结果如下。

| 配置 | 测试缺失特征 MSE ↓ | 测试 BAcc ↑ |
|---|---:|---:|
| 重建权重 500 | 0.007064 | 37.27% |
| 重建权重 2500 | 0.004114 | 36.98% |
| 重建权重 5000 | 0.003931 | 38.43% |
| 重建权重 50000 | 0.003896 | 39.54% |

这些都是 seed0，分类训练 50 轮。这里的 MSE 是缺失导联的 CNN 特征误差，不是原始 EEG 波形误差。

在这几组配置里，增大重建权重后，缺失特征 MSE 降低了，但分类没有同步、单调地提高。同样训练 50 轮的固定补全 A 是 40.29%，这四组三阶段结果都没有超过它。

表征方面，目前已有全导联和少导联输入下的可视化，但缺少统一的探针和训练前后对照，还不能确认三阶段改善了解耦。

另外，两阶段分类训练 30 轮，三阶段分类训练 50 轮，分支训练的输入和损失权重也发生了变化。因此，不能把两者的成绩差异直接归因于训练阶段数量。

## 7. 当前结论和下一步

目前比较明确的是：固定 Prototype 的分类收益有限；当前两阶段 D 没有带来分类提升；三阶段部分配置的缺失特征 MSE 更低，但还没有形成稳定的分类优势。

现在还不能说三阶段已经实现了更好的解耦，也不能说补得更像就一定分得更准。

下一步需要统一训练设置和多个 seed，补齐主模型的分支探针与交换诊断，并评估固定 Prototype 在相同测试范围下的 MSE。这样才能分别判断：表示有没有分开、缺失特征有没有补好，以及这些补全信息有没有帮助分类。
