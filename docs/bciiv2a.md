# BCI-IV-2A 实验结果

## 首先汇报的两个结果

### 1. A/O/N：符合预期，O > A > N

| 方法 | 含义 | Test BAcc |
|---|---|---:|
| O(freeze CNN) | 全导联 | **47.92%** |
| A(freeze CNN) | 固定 Prototype 补全 | **47.40%** |
| N(freeze CNN) | 少导联，不补全 | **46.35%** |

可以直接说：

> 首先，A/O/N 的结果符合预期：全导联 O 最好，固定 Prototype 补全 A 居中，仅使用少导联的 N 最低，测试 BAcc 分别为 47.92%、47.40% 和 46.35%。固定补全相比少导联提高了 1.04 个百分点，说明在当前 seed0 实验中，加入对应导联的平均特征对分类有帮助。

### 2. D：已完成实验中的最好结果为 47.48%

| D 配置 | Test BAcc | Test Kappa | 与 A 的差值 |
|---|---:|---:|---:|
| 动态补全，以重建为主；含额外 corrector 时间编码，保留正则 | **47.48%** | **0.2998** | **约 +0.09 个百分点** |

该结果来自 `D_pipeline/seed0_20260930_144901_1214809/`：Stage1 重建权重 50、正则权重 0.001，对比及交换损失权重全部为 0；Stage2 按验证 BAcc 选中 epoch 30，Val BAcc 46.27%。

可以直接说：

> 第二，当前已经完成的 D 配置中，最好测试 BAcc 是 47.48%。这组保留动态补全结构，主要通过重建训练，关闭了对比损失和交换约束，同时使用额外时间编码并保留少量正则。它的效果与固定补全 A 的 47.40% 接近，数值上略高，但尚未超过全导联 O。当前可以说动态补全已经达到接近固定补全的水平，还不能说带来稳定提升，也不能把这个最好结果当作解耦成功的证据。


### 3. 其他 D 实验：怎么改、想验证什么、效果如何

前五组采用两阶段流程：先冻结 CNN 训练 corrector，再加载该阶段的最佳 checkpoint，冻结 CNN/corrector，训练下游 Transformer 和分类头；轮数为 20＋50。均使用 CBraMod 跨被试划分、seed0，并按验证 BAcc 选择分类 checkpoint。

下面“想验证什么”是对这些改动的实验解释，不表示已由结果证明。

| 实验 | 怎么跑、改了什么 | 想验证什么 | Test BAcc | 观察 |
|---|---|---|---:|---|
| 原始 D | 重建 20；正则 0.001；subject summary/correction 对比各 0.02；subject/task 交换各 5/20；无额外时间编码 | 建立动态补全的初始对照 | 46.18% | 低于 A，也略低于 N |
| 加入时间编码 | 损失权重沿用原始 D；corrector 加入额外时间编码 | 让补全模块区分不同时间片，检查时间信息是否有帮助 | 47.31% | 比原始 D 高约 1.13 个百分点，接近 A |
| 加强双分支约束 | 保留额外时间编码；重建提高到 50；subject/task correction 对比各 1；交换各 1；summary 对比关闭；正则 0.001 | 检查同时约束 subject/task 修正分支能否改善补全 | 47.31% | 与上一配置相同，未观察到进一步提升 |
| 以重建为主 | 保留额外时间编码；重建 50、正则 0.001；所有对比及交换权重置零 | 去掉解耦约束，检查直接拟合缺失 CNN 特征是否足够 | **47.48%** | 已完成 D 配置中最高，与 A 接近 |
| 关闭重建 | 保留额外时间编码；subject/task correction 对比各 1、正则 0.001；重建、summary 对比及交换关闭 | 检查缺少重建监督时，仅对比目标能否产生有用的补全特征 | 44.18% | 明显下降；这组设置下，仅对比监督不足 |
| 分开解耦与重建 | 先解耦 20 轮，再继承 checkpoint 仅重建 20 轮，最后冻结补全模块分类 50 轮；当前脚本无额外 corrector 时间编码 | 检查分阶段优化是否能减少不同目标之间的干扰 | 46.79% | 已完成，介于原始 D 与 A 之间，未超过以重建为主的配置 |

三阶段运行目录为 `D_pipeline_3stage/seed0_20261009_134040_3529941/`。分类按验证 BAcc 选中 epoch 10：Val BAcc 46.09%，Test BAcc 46.79%，Test Kappa 0.2905。它同时改变了训练流程和时间编码设置，不能作为单独验证“分阶段更好”的严格对照。

可以直接说：

> 我进一步做了几组 D 的配置对照。原始动态补全是 46.18%；加入时间编码后达到 47.31%。再加强 subject/task 双分支约束，结果仍是 47.31%，没有继续提高。关闭对比和交换、以重建为主时，达到当前最高的 47.48%；反过来关闭重建、只保留对比和正则时，降到了 44.18%。所以目前的结果提示，补全特征需要重建目标来约束，解耦约束如何加入还需要进一步研究。我也尝试了先解耦、再重建、最后分类的三阶段训练，目前是 46.79%，还没有超过以重建为主的配置。

这些是单 seed 的配置探索，不能证明时间编码或某一损失的独立因果效果，也不能证明潜变量已经成功解耦。






数据协议：CBraMod 跨被试划分。以下结果均为实际 seed 0 的测试集 balanced accuracy（BAcc）；分类 checkpoint 按验证集 BAcc 选择，报告该 epoch 对应的测试结果，未按测试集选点。

## 可以直接口述的部分

> 我先在 BCI-IV-2A 上使用 CBraMod 的跨被试划分，比较全导联、少导联和固定 Prototype 补全。当前 seed0 的测试 BAcc 分别是：全导联 O 为 47.92%，固定补全 A 为 47.40%，少导联 N 为 46.35%。因此，这一次实验呈现 O > A > N：固定 Prototype 补全相比少导联提高了 1.04 个百分点，也缩小了与全导联的差距。这为继续研究补全提供了初步依据。
>
> 在此基础上，我尝试动态补全 D，希望用当前样本的信息修正固定 Prototype。原始 D 的测试 BAcc 为 46.18%，暂时没有超过固定补全。后续消融中，以重建为主的配置达到 47.48%，与固定补全接近；关闭重建、仅保留双分支对比和正则的配置则为 44.18%。这些结果提示重建目标可能很重要，但几组配置还涉及时间编码和损失权重变化，不能把差异归因于某一个因素。
>
> 现在我进一步把训练拆成三步：先训练解耦，再继承权重只优化重建，最后冻结 CNN 和补全模块，训练下游 Transformer 与分类头。目的是检查分开优化是否比联合优化更有效。当前三阶段测试 BAcc 为 46.79%，仍是单 seed 的探索，后续需要用多 seed 验证效果，并检查重建训练后解耦结构是否保留。

注意：A 是固定 Prototype 补全，N 才是仅使用少导联。47.48% 比 A 高约 0.09 个百分点，仅相差约一个测试样本，不能称为稳定超越 A。额外时间编码那组相较原始 D 提高约 1.13 个百分点，也只能作为单次运行观察。
