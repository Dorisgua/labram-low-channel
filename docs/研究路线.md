# EEG 缺失导联补全研究

## 1. 固定 Prototype 补全
- 为什么做
  - 用训练集平均特征补偿缺失信息
- 做了什么
  - TUEV 预实验
  - 多数据集 A/O/N 对照
- 观察
  - 部分设置有收益
  - 其他设置持平或下降
- 为什么进入下一步
  - 固定模板无法随当前样本变化

### 1.1 两阶段训练
- Stage1
  - 同时学习解耦与补全
- Stage2
  - 冻结补全模块，训练分类
- 做了哪些尝试
  - 损失权重调整
  - 多数据集 Stage1
- 观察
  - 部分实验重建误差下降
  - 分类没有稳定提升
  - 少导联下部分表征结构变弱
- 为什么进入下一步
  - 检查拆开解耦和适配是否有帮助
  - **三阶段训练**
    - Stage1：全导联学习
    - Stage2：少导联适配与补全
    - Stage3：分类
    - 做了哪些检查
      - 三行表征对照
      - 重建损失权重对照
      - 固定 Prototype 分类对照
    - 观察
      - 适配后呈现部分表征结构
      - 部分设置重建更准确
      - 分类仍未超过固定基线
