# EEG 缺失导联补全研究

## 1. 固定 Prototype 补全

用训练集平均特征补偿缺失导联信息，完成 TUEV 预实验和多数据集 A/O/N 对照。

### 1.1 做法
- 完成九数据集AON实验框架
- 冻结 CNN / 全量微调对照
  - 问题：冻结预训练特征是否限制了分类任务适配？
  - 尝试：ERP-Core 历史实验比较冻结 CNN 与 full finetune
  - 结果：已有不同训练方式的分类结果；分类器与读出设置也有差异，不能把所有差距都归因于是否冻结 CNN


### 1.2 效果
- 部分设置有收益
- 其他设置持平或下降
- 固定模板无法随当前样本变化

### 1.3 下一步

尝试根据当前样本动态调整补全特征，探索以下两种做法。

#### FiLM

- 做法：根据观测特征预测缩放和平移，动态调整补全特征
- 效果：下降
- 具体配置与效果还需补充来源

#### 两阶段训练

下面的“问题”和“可能原因”用于说明尝试目的，不表示原因已被证实，也不代表全部历史尝试的实际先后顺序。ERP-Core 的配置、结果和诊断来源见[实验整理](ERP_Core_两阶段与三阶段实验整理.md)。

- 做法
  - 双分支修正：Prototype + subject 修正 + task 修正
  - 尝试分别表达个体与任务信息
  - Stage1：同时学习解耦与补全
  - Stage2：冻结补全模块，训练分类
  - 已尝试损失权重调整和多数据集 Stage1
- 效果
  - 部分实验重建误差下降
  - 分类没有稳定提升
  - 少导联下部分表征结构变弱，仍需配套诊断验证
- 中间做过的尝试
  - 修正量范围限制 → 取消限制
    - 问题：动态修正是否过大？反过来，范围太小是否限制补全能力？
    - 尝试：旧版使用 `d = correction_scale × tanh(output)`；scale=0.02 时，每个分支约限制在 ±0.02，两分支总修正约限制在 ±0.04
    - 后续：当前 ERP-Core 两阶段与三阶段版本去掉 tanh 和缩放，直接相加
    - 结果：已确认实现变化；取消限制的独立分类和重建收益仍待核实
    - 来源：旧实现为 `../LaBraM-unified-AON-dynamic/modeling_dynamic_stage1.py` 中的 `correction_scale × tanh`；当前实现见 `modeling_dynamic_stage1.py::_encode_dynamic_tokens`
  - 修正量平方正则
    - 问题：不直接限定范围时，是否需要通过损失控制修正幅度？
    - 尝试：惩罚 `mean(d_sub²) + mean(d_task²)`，属于软约束，没有固定输出边界
    - 设置：历史配置及 BCI-IV-2A 实验保留正则权重0.001；当前 ERP-Core 主配置为0
    - 结果：没有核实仅改变正则权重的受控效果
    - 来源：ERP-Core 配置见[实验整理](ERP_Core_两阶段与三阶段实验整理.md)，BCI-IV-2A 配置见[BCI 实验记录](bciiv2a.md)
  - 重建、对比与交换损失权重调整
    - 问题：缺失特征拟合与分支约束的配合可能不合适
    - ERP-Core：当前主配置重建500、subject/task correction对比各50、交换各1；分类 BAcc 37.43%，未超过 A/N
    - BCI-IV-2A：保留时间编码，加强双分支约束并调整重建/交换权重，BAcc 47.31%，未比时间编码配置继续提高
    - 局限：多项权重一起变化，不能确认某一项是原因
    - 来源：ERP-Core 见[实验整理](ERP_Core_两阶段与三阶段实验整理.md)，BCI-IV-2A 见[损失配置对照](bciiv2a.md)
  - 关闭直接重建损失
    - 问题：仅靠分支约束能否产生有用的补全特征？
    - ERP-Core：直接重建权重置0，保留 correction对比和交换；已有表征图与线性探针，仍观察到交叉信息
    - 注意：交换损失仍包含重建，不是完全没有重建约束；该诊断 checkpoint 不是主分类 checkpoint
    - BCI-IV-2A：关闭直接重建和交换，保留双分支对比与正则，BAcc 44.18%，低于原始 D 的46.18%
    - 来源：ERP-Core 见[解耦诊断与消融](ERP_Core_两阶段与三阶段实验整理.md)，BCI-IV-2A 见[消融实验记录](bciiv2a.md)
  - 关闭对比与交换，以重建为主
    - 问题：解耦约束是否带来额外收益，直接拟合缺失特征是否足够？
    - ERP-Core：仅重建消融 BAcc 37.98%，仍未超过 N 39.73% 和 A 40.29%
    - BCI-IV-2A：保留时间编码和少量正则，以重建为主达到47.48%，接近 A 的47.40%，尚不能称为稳定超越
    - 来源：ERP-Core 见[仅重建消融](ERP_Core_两阶段与三阶段实验整理.md)，BCI-IV-2A 见[以重建为主的实验](bciiv2a.md)
  - 加入额外 corrector 时间编码
    - 问题：多时间片样本中，补全模块是否缺少显式时间位置信息？
    - 做法
      - 给观测与缺失 token 加入时间位置编码
    - 效果与后续决策
      - BCI-IV-2A
        - 观察：现有结果有正向变化，仍需核对
        - 结果记录：原始 D 46.18%，加入时间编码的配置为47.31%
        - 决策：继续验证
        - 下一步：固定其他配置，比较有／无时间编码
        - 来源：[时间编码对照](bciiv2a.md)
      - SHU
        - 观察：现有两次运行低于无编码结果
        - 结果记录：原始主运行56.11%，加入时间编码的两次运行53.15%和52.51%
        - 决策：暂停进一步调参
        - 原因：尚未观察到收益，优先投入主线实验
        - 保留问题：配置是否一致，下降是否来自时间编码
        - 来源：[时间编码实现与结果](answer.md)
      - 其他数据集
        - 状态：尚未测试
        - 决策：暂不扩展
        - 当前 ERP-Core 主实验未使用额外 corrector 时间编码
  - 检查难补样本与导联 → 增加真实观测导联
    - ERP-Core 问题：部分样本补全误差较高，C5/C6 等导联较难预测
    - 检查：样本误差长尾、逐导联 MSE、波形粗糙度与重建误差的关系
    - 可能原因：观测信息不足，或快速变化成分更难预测；相关分析不能证明因果
    - 尝试：观测导联从12增加到14（加入 C5/C6），再探索21导联，并做 A/N/D 对照
    - 结果：旧文档记录部分缺失特征 MSE 下降，分类未同步改善；缺失集合、seed和训练配置变化，需分开比较
    - 来源：[12→14/21 导联实验与误差分析](尝试从12导联变成14导联看AND情况.md)
  - 可能是融合方式不对：修改成attention
    - 属于待验证的解释，具体配置与效果还需补充来源
- 下一步
  - 三阶段训练
    - 检查先全导联学习、再少导联适配是否有帮助
    - 来源：ERP-Core 见[三阶段实现、结果与诊断](ERP_Core_两阶段与三阶段实验整理.md)，BCI-IV-2A 见[三阶段实验记录](bciiv2a.md)
    - 做法
